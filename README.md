# 繁梦空间桌面客户端 v1.0.0 安装包

这个分支只存放安装包（Git LFS），源码在 main 分支的 `desktop/` 目录。

| 平台 | 文件 |
| --- | --- |
| Windows 10 / 11（64 位） | FanmengSpace-Setup-1.0.0.exe |
| macOS 12+ · Apple 芯片 | FanmengSpace-1.0.0-mac-arm64.zip |
| macOS 12+ · Intel 芯片 | FanmengSpace-1.0.0-mac-x64.zip |

把本目录全部文件（包括 latest.yml、latest-mac.yml 和 .blockmap）上传到服务器项目目录下的 `desktop-releases/`，
网站 /download 页面和已安装的客户端就会识别到这个版本，详见 main 分支 deploy/DEPLOY.md 第 9 节。
