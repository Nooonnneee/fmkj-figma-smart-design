| 主按钮     | 墨黑 `oklch(0.205)` + **全圆胶囊 9999px** | 品牌紫 + 8px                 |
| 卡片圆角   | **16px**                                  | 12px                         |

> 我用 `elementHandle.screenshot()` 单独截这两个元素，**品牌 logo 和二维码都清晰可见**。
> 所以页面本身没问题，是截图工具的局限。
>
> **区域特写才是图片区域的可靠证据。**

## 七、这一轮踩的坑（已写进代码注释与 `memory/learnings.jsonl`）

1. **CSS 变量按最近祖先取值，不看选择器优先级。**
   Astryx 的 `<Theme>` 会在中间层重设 `--radius-element: 8px`（`.xrw1vgx` 类），
   在 `html` 上覆盖 token 完全没用 —— 必须在**元素上**给终值。

2. **胶囊只该给操作按钮。**
   一开始把侧边栏导航也做成胶囊，239px 宽的条目变成一根根药丸，很难看，已撤回。

3. **`{/* 注释 */}` 不能紧跟 `{cond ? (`。**
   JSX 要求 `? (` 后必须紧跟元素，注释得放在表达式外面（让我挂了一次 500）。

4. **数元素前先看尺寸。**
   我一度以为 `/templates` 把 12 个模板渲染了两遍，实际是「怎么选」表格里的
   文字链接（112×20）被算进了卡片（368×421）。

5. **视觉模型的结论必须实测复核。**
   它报的「设置页主题状态矛盾」「文档风格预览空白」两条都是**假阳性**：
   前者是我的截图脚本用 JS 强改 CSS 没改 React state，后者是截图早于 lazy-load。

6. **重启 dev server 一律用 `/tmp/start-dev.sh`。**
   手动 `pkill` 后新 shell 不继承 `export` 的环境变量，会 500
   （`缺少环境变量 DATABASE_URI`）。这个坑我踩了三次。

7. **改 UI 前先 grep 有没有现成组件。**
   模板缩略图的整套机制（`buildTemplateGallery` + `TemplateCard` +
   `/templates/<slug>/slides`）**早就存在**且在公开页/插件详情页都在用，
   模板中心只是没用它 —— 我差点重造一遍。
