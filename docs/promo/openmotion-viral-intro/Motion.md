# 繁梦空间 · 爆款介绍（竖屏）

## Brief
- Audience: 全屋智能设计师 / 集成商 / 灯光弱电门店
- Platform: 抖音 / 小红书 / 视频号（9:16）
- Length: 28s · 1080×1920 · 30fps
- Promise: 点位图直接出报价与横版提案，告别 Excel/PPT 通宵

## Brand Kit
- Name: 繁梦空间（FMKJ）
- Tagline: 点位图直接出报价
- Palette: ink `#0b0c0f`, gold `#f5c26b`
- Typography: Inter + Droid Sans Fallback
- Assets: 真实点位图、工作台截图、提案封面、品牌 mark
