## 在本地 OpenMotion 继续改

1. 打开本地 Studio（你之前的 `http://127.0.0.1:54722` 一类地址）
2. **All projects → Import projects**
3. 导入 [`fmkj-openmotion-project.zip`](./fmkj-openmotion-project.zip)
4. 用 Agent / 时间轴改文案、节奏、配乐后再导出
